# Professional

- [roadmap.sh](https://roadmap.sh) - step-by-step learning paths for developer roles, useful to plan what to learn next.
- [GitHub Student Developer Pack](https://education.github.com/pack) - free developer tools for students, including GitHub Copilot and cloud credits.
- [regex101](https://regex101.com) - test regular expressions and see an explanation of every part of them.
- [Semantic Versioning](https://semver.org) - rules for version numbers, so users know when an update can break their code.
- [Keep a Changelog](https://keepachangelog.com) - how to write a changelog that people can read, with clear examples.
- [Refactoring Guru](https://refactoring.guru) - design patterns and refactoring explained with pictures and code examples.
